# Teaching Income

App quản lý buổi dạy tối ưu cho iPhone.

## Cấu trúc
- `index.html`: toàn bộ ứng dụng
- `icon.png`: icon app
- `manifest.json`: thông tin PWA

## GitHub Pages
Upload toàn bộ file vào repository, bật GitHub Pages ở:
Settings → Pages → Deploy from branch → main → /(root).

Sau khi mở bằng Safari trên iPhone, có thể chọn:
Share → Add to Home Screen.

Dữ liệu hiện được lưu trên thiết bị bằng localStorage.
